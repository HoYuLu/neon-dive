# NEON//DIVE

赛博朋克风格的高机动 FPS Demo，Windows x64 免安装。

跑墙、蹬墙跳、TAP-STRAFE 与滑铲延续同一套高机动移动系统；钩索与穿越门两套战术技能，上高楼、翻掩体、穿墙都靠它。

## 下载

[Windows x64 免安装版（GitHub Releases）](../../releases/latest)

下载后解压，运行 `NEON DIVE.exe`，不需要把 exe 单独拖出文件夹。

首次运行可能触发 Windows SmartScreen，因为未签名，选择「更多信息」→「仍要运行」。

## 操作

| 输入 | 动作 |
| --- | --- |
| WASD | 移动 |
| Shift | 冲刺；跑墙时配合方向贴墙 |
| Space | 跳跃 / 二段跳 / 蹬墙跳 |
| C | 滑铲 |
| 左键 / 右键 | 射击 / 机瞄 |
| R | 换弹 |
| Q | 切换枪械 |
| 1 / 2 | 切换携带的两把枪 |
| 3 | 切换近战 |
| T（长按） | 战术技能：预览，松手释放 |

## 战术系统

设置里在「钩索 / 穿越门」中二选一，长按 `T` 预览、松手释放。

### 钩索

- 有效距离 50m，钩爪飞行 100 m/s
- 命中瞬间抓地停顿 0.3s，期间按空格起跳、开始牵引
- 牵引按 Apex S3 原版规则：沿绳速度 1.8 → 28.9 m/s 爬升 1.5s（只加不刹），横绳速度衰减 15.4 m/s²，下落速度保留，WASD 用空中加速摆动（上限 15.2 m/s），重力降到 25%~70%
- 断钩：视线离开钩点超过 90°、钩点被挡 0.15s、贴近钩点 1.27m、低速（<9 m/s）持续 1.5s、或挂绳 4s；跳跃即脱钩并给竖直加速
- 2 格充能，每格 15s

### 穿越门

- 可开在墙面、地面和屋顶；入口沿视线取紧贴的下一面，所以出口在墙的另一面
- 水平平台可以双向打穿：从下往上打，底面挂线、顶面不挂
- 高处门会垂一条斜向地面的蓝色连线，不会埋进建筑：
  - 碰到连线 → 先到该门的位置，再立刻穿到另一扇门
  - 地面 / 屋顶上的门走过就穿
  - 建筑顶部平面（朝上的屋顶）不挂线
- 2 格充能，每格 15s；场上最多 6 对门，每对存在 30s
