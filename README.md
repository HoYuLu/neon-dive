# NEON//DIVE

高机动 FPS Demo

贴墙跑、蹬墙跳、TAP-STRAFE 与滑铲保速属于同一套高机动移动系统；动作可以自由串联，上手门槛低。找到节奏后，短距离里也能打出流畅连段。

## 下载

[Windows x64 免安装版（GitHub Releases）](../../releases/latest)

整包解压后运行 `NEON DIVE.exe`；不要把 exe 单独移出文件夹。

首次启动可能触发 Windows SmartScreen（构建未签名）：选择「更多信息」→「仍要运行」。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD | 移动 |
| Shift | 冲刺；贴墙配合方向键触发贴墙跑 |
| Space | 跳跃 / 二段跳 / 蹬墙跳 |
| C | 滑铲 |
| 左键 / 右键 | 射击 / 开镜 |
| R | 换弹 |
| Q | 切换武器 |
| 1 / 2 | 切换主武器 |
| 3 | 切换近战 |
